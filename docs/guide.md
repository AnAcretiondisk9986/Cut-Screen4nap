# 使用指南

## 使用场景

笔记本放在宿舍床上桌、外接两台显示器、底部有散热支架。收尾操作做完 → 放好键鼠 → 躺下，此时需要屏幕全黑但不能合盖（合盖挡进风口、且 Windows 电源菜单没有「只关屏」这一项）。

Cut-Screen 用软件动作替代合盖：**灭屏但不挂起系统，任务继续跑，早上碰一下就回来**。

## 三档详解

| | 休眠（无任务） | 挂机（有任务） | 午睡（临时补觉） |
|---|---|---|---|
| 核心 | `shutdown /h` | `PowerRequest(SystemRequired)` + `DpmsOff()` | 三屏纯黑全屏窗口 |
| 下载 / Agent | 停，内存写盘保留 | 照常跑 | 照常跑 |
| 屏幕 | 全黑 | 真黑 | 深灰（IPS 透灰，VA 接近全黑） |
| 锁屏 | 唤醒后本就是锁屏 | 默认关，设置里可开 | 关 |
| 退出 | 无退出态 | 任意输入 | 任意输入 |
| 恢复 | 按电源键，几十秒 | 秒回桌面 | 秒回、零闪烁 |
| 改电源计划 | 否 | 否 | 否 |
| 崩溃快照 | 不需要 | 需要 | 需要 |

### 休眠档

一次性动作，不建快照、不保活。休眠后整机断电，散热不再是问题，想合盖也行。

- 本机若未启用休眠，程序会提示并尝试 `powercfg /hibernate on`（需管理员，只需一次）。
- 只能按电源键唤醒，键鼠叫不醒 —— 这是 S4 特性，不是 bug。
- 部分主板 BIOS 的 `USB Wake from S4` 会让「放键盘」那一下把刚休眠的机器碰醒，第一晚留意一次。

### 挂机档

`PowerCreateRequest` 只挂 `SystemRequired`，**绝不挂 `DisplayRequired`** —— 只保系统不睡，允许屏幕随便灭。失败时回退到 `SetThreadExecutionState` 常驻线程。主动发一次 `DpmsOff()`，之后每 60 秒重暗一次，压住播放器 / 下载工具刷 `ES_DISPLAY_REQUIRED`。

外接屏可选用 DDC/CI（`VCP 0xD6`）关背光：只灭面板背光、视频链路保持，Windows 不会以为显示器被拔了，窗口不回挤主屏、桌面图标不重排。

### 午睡档

三屏各盖一个 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST` 纯黑窗口，不吃焦点、不进 Alt+Tab、点击不穿透。

额外挂 `PowerRequestDisplayRequired` **阻止系统把显示器送进 DPMS 待机** —— 这是关键：显示器全程供电、视频链路稳定，退出时不需要唤醒、不会重训练链路，因此零闪烁零断连。深灰是它的代价。

退出时三个窗口先统一隐藏再销毁，避免逐块露出桌面。

### 为什么午睡档不是「全黑」

早期版本曾把「关闭显示器」超时收紧到 1 秒，结果显示器自己待机、意外变全黑，退出时又发 `MONITOR_ON` 强制上电，造成外接屏连接 / 断联和多次闪烁；`PowerSetActiveScheme` 还会重配置显示子系统两次。

现在两档都**完全不修改电源计划**：

- 防「播放器刷空闲计时」由 60 秒重暗定时器负责（挂机档）
- 防「系统自己关屏」由 `DisplayRequired` 句柄负责（午睡档）

两者都是进程级、不改任何全局设置。要彻底黑且零闪烁，用挂机档。

## 使用流程

1. 在主界面点一档，或托盘右键菜单选一档。
2. 有 20 秒可取消倒计时，够你放好键鼠、躺下（时间可调）。
3. 进入档位后主窗口自动隐藏，托盘图标变色。
4. 移动鼠标或按任意键即退出，反序还原所有设置，主窗口自动回来。
5. 点窗口 `×` 只是缩到托盘；真正退出用托盘右键 →「退出程序」。

进入后有 3 秒宽限期，吃掉放键盘那最后一下输入，之后才开始检测。整个档位期间每 60 秒重发一次关屏 / 重新校正黑窗口，同时让黑窗口跟随显示器热插拔自动补齐 / 移除。

## 显示器枚举

屏幕是运行时动态枚举的，**没有写死设备 ID**：

- DPMS 走 `HWND_BROADCAST` 关当前全部显示器，程序不需要知道有几块、叫什么
- 黑窗口 / DDC/CI 在每次进入档位时用 `EnumDisplayMonitors` 现查拓扑
- `MonitorInfo` 里的 `DeviceName` / `IsPrimary` 字段代码里根本没用到

所以换地点、换显示器、从 3 屏变 1 屏都不用改配置。运行中插拔显示器由 60 秒重暗循环补齐 / 移除黑窗口。

## 首次使用建议

### 1. 跑自检

只读，不会关屏 / 锁屏 / 休眠：

```powershell
dotnet run -c Release -p:DefineConstants=SELFTEST -p:OutputType=Exe
```

结果同时输出到控制台和 `bin/Release/net10.0-windows/selftest.log`。检查显示器枚举、电源方案读取、`GetLastInputInfo`、DDC/CI 探测、休眠可用性、配置与快照读写。

### 2. 午睡档第一晚先用它

零硬件依赖、最稳、深灰可接受。确认「任意输入即退出」和多屏黑窗口位置都正常，再试挂机档。

### 3. 挂机档的 DDC/CI 默认关闭

`VCP 0xD6 = 0x04` 会把显示器送进深睡，部分型号此时不再响应 DDC/CI 写回 `0x01`，结果就是「黑了但背光叫不醒」。默认走纯 DPMS（`SendMessageTimeout` 广播，带 `SMTO_ABORTIFHUNG`，不会被卡死的顶层窗口挂住）。

想启用 DDC/CI，先去**设置 → 检测外接屏 DDC/CI 校准**跑一次：它会实测「写 Off → 写回 On」是否都能成功，全通过再勾上开关。更省事的一次性办法：在两台显示器的 OSD 里关掉 `Deep Sleep` / `DP 自动休眠`，很多掉链问题当场消失。

### 4. 验收保活是否挂对

档位运行时另开终端：

```powershell
powercfg /requests
```

- **挂机档**：SYSTEM 段应出现 `Cut-Screen`，DISPLAY 段必须为空
- **午睡档**：SYSTEM 段和 DISPLAY 段都应出现 `Cut-Screen`（这里 DISPLAY 有值是对的）

### 5. 崩溃自恢复

挂机 / 午睡档改的持久化设置会落盘快照到 `%AppData%\CutScreen\snapshot.json`。进程被强杀或断电后，下次启动先还原再正常工作。

## 已知边界

- 屏幕灭了、灯还亮着：显示器待机指示灯、笔记本电源灯、键盘背光、RGB 软件收不掉。真按「全黑」要求，胶带最有效。
- 挂机档默认不锁屏，靠「键鼠已放置」的物理隔离兜底。开了锁屏后任意输入只会点亮锁屏，仍需输 PIN。
- 锁屏开启时，`WTSRegisterSessionNotification` 的会话事件目前只做了轻量 `Sleep(400)` 兜底，未严格等待 `WTS_SESSION_LOCK`，极个别机器上可能偶发「锁了但屏还亮着」，重暗定时器会在 60 秒内兜住。
- 休眠后整机断电，散热不再是问题，可以合盖。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 弹「You must install .NET Desktop Runtime」 | `runtimeconfig.json` 缺失 | 跑完整 `dotnet build`，或把四个产物文件一起复制 |
| `dotnet build` 报文件被锁定 | 有 `CutScreen.exe` 正在运行 | 托盘右键 →「退出程序」，或按 PID 精确 `taskkill` |
| 黑窗口退出时闪烁 / 外接屏断连 | 旧版会改显示器超时并发 `MONITOR_ON` | 升级到当前版本，两档均已不碰电源计划 |
| 休眠档提示需管理员 | 本机未启用 hibernate | 允许程序自动执行 `powercfg /hibernate on`，或手动以管理员运行一次 |
| 屏幕数量显示为 1 | 外接屏未接入或被会话隔离 | 属于预期，接上显示器后重新进档位即可 |
| 光学鼠标自己把档位退出了 | 桌面轻微震动造成光标位移 | 设置里勾「忽略光学鼠标微小抖动」，调阈值 |
